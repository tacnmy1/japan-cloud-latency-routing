## CN2、9929、CMIN2 到底是什么，日本节点为什么也要看

这三个代号决定了你的日本云服务器在中国三家里分别走哪条路。

- **CN2 GIA（AS4809）**：中国电信的精品承载网，相比默认的 163 骨干，晚高峰拥塞明显更少。
- **AS9929（CUII）**：中国联通的精品国际线路，区别于大多数国际流量默认被丢进去的 AS4837。晚高峰这两条路的差别，基本就是「站点能打开」和「一直转圈」的差别。
- **CMIN2（AS58453）**：中国移动的国际优化网络。移动用户基数最大、国际路由历史上最差，CMIN2 就是补这个短板。

三家同时走精品回程，在日本节点上并不算常见。相当多的「中国优化」日本 VPS 只优化电信和联通，移动走 CMI 或者干脆走普通路径。

这里有一处值得说明的细节：GoMami 官方 Locations 页面写的是「中国电信 CN2、联通 AS9929、移动 CMI 直连」，移动那条写的是 CMI；而第三方库存站和实测记录普遍标注为 CMIN2，2026 年 4 月的实测也显示广州移动 33ms 直连上海 CMIN2。两边对移动回程的描述有差别，实测更接近 CMIN2 的说法。如果你特别在意这一条，买之前自己跑一遍 traceroute 确认最稳。

还有一个更值得参考的官方信息：GoMami 文档里的节点选择表写得很直白——面向华南用户选香港，面向全中国用户选香港，游戏加速选香港；日本只出现在「面向华北用户」那一行，理由是联通路由优化好。

官方自己也没把日本包装成「全中国最快」。如果访客集中在广东、福建，香港节点物理距离更近、官方标称延迟 <30ms，本来就更合适。日本节点的价值在华北，以及联通用户占比高的场景。

## 延迟实测：官方标 <50ms，实际落在什么区间

官方 Network FAQ 给的口径是日本节点到中国大陆 <50ms，香港 <30ms，新加坡 <70ms，并注明实际延迟随本地 ISP 和网络状况变化。

第三方实测的数字略高一些，也更接近真实体感。2026 年 4 月一份针对 JPN.Pulse.Nano 的测试记录显示：广州电信经香港中转 47ms、最终约 57ms；广州联通到上海 CUG 27ms、到 AS9929 54ms；广州移动到上海 CMIN2 33ms。同一份测试里 Speedtest 跑出 1036 Mbps 上行 / 864 Mbps 下行。

2025 年 12 月另一份针对 JPN.Pulse.Mini 的测评数据更贴近日常使用：深圳电信（本地 500Mbps）到日本 404–417 Mbps，济南联通（本地 500Mbps）541–545 Mbps，基本能跑满本地带宽。

移动那边是短板。同一份测试里，广东移动（1Gbps）上行只有约 35.6 Mbps，还反复出现 0.00 Bytes/sec 的停顿；宁波移动上行 33.9 Mbps、下行 568 Mbps。上行被 QoS、下行正常，这个特征在多份测试里重复出现。如果业务是移动用户上传素材、直播推流、大文件回传，这一点必须先算进去。

需要说明的是，上述测评中至少有一台的测试机由厂商提供，属于送测而非完全独立购买。延迟和解锁结果也会随城市、运营商、时间段和 IP 变化，别把某一组数字当成永久承诺。

## 哪些人该买日本节点，哪些人该去看香港

判断标准可以归成一句话：看访客在哪个区域、用哪家运营商。华北且电信联通为主，日本节点合适；华南、需要覆盖全中国、或做游戏加速，官方建议是香港。

**适合买 JPN Pulse 的：**
- 访客以华北地区为主、电信联通占比高，官方把日本列在「面向华北用户」这一行；
- 需要日本 IP 做建站、跨境电商后台、API 服务，同时又要中国访问速度；
- 需要 Windows 跑 .NET 或远程桌面——只有 Pro（$169）和 Ultra（$338）符合；
- 对晚高峰稳定性要求高、能接受溢价，把服务器当长期运行的生产环境。

**不太适合的：**
- 预算敏感的个人用户。$29/月已经是这条线的地板价，同价位在日本 VPS 市场能买到配置更高的机器，只是线路不同。
- 以中国移动用户为主、且需要大量上传的场景。多份实测显示移动上行被明显 QoS。
- 需要大容量本地存储。最贵的 Ultra 也只有 300 GB NVMe，做媒体库或大数据库得另配对象存储。
- 需要住宅 IP 或原生 IP 才能过的业务，比如 TikTok 日本区运营、部分日本本土站点。GoMami 官方没有对 IP 属性做任何承诺，第三方测试结果也不一致，这类需求应该去找专门的住宅代理，别拿 VPS 硬顶。
- 主力用户在华南，或需要覆盖全中国、做游戏加速。官方自己的建议就是香港。

计费上有一个对建站用户友好的点：只计出站流量，入站完全免费。跑下载型或 API 型业务时，这一条的实际价值不小。

**日本云服务器需要备案吗？** GoMami 的官方页面和文档没有就备案问题作任何说明。服务器托管在日本，不涉及中国大陆的 ICP 备案流程，这一点属于一般性常识；具体合规要求仍以服务条款和适用法律为准。

**官方标 <50ms，为什么我这里测出来 60ms 多？** 官方给的是典型值。实测受城市、运营商、接入方式和时间段影响，广州地区第三方测试大致落在 30–60ms 区间，北方联通用户往往更接近标称值。

**SSH 连不上，或者 IP 在国内访问不了怎么办？** 官方建议先确认是不是全球都不可达（排除服务器本身问题），再用 ping / traceroute 定位路径，然后提工单核实 IP 状态。换 IP 走自助流程，控制面板提交即可，$5 一次、立即生效，旧 IP 会立刻释放且无法找回，换之前先确认手上有更新 DNS 的权限。
